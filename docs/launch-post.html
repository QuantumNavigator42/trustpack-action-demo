TrustPack Action v0.1.0 is live.

TrustPack generates a buyer-ready security due diligence pack from a GitHub repository: executive summary, repository evidence JSON, security controls, dependency inventory, workflow risk report, remediation checklist, vendor-security-questionnaire starter, and optional HTML index.

The wedge is simple: when a prospect asks for security documentation, teams should not have to scramble through repo settings, workflow YAML, dependency manifests, and security files manually.
